# Contributing

Keep changes small, preserve existing site content and the live Supabase review workflow, and test on desktop and mobile.

1. Create a feature branch.
2. Run `node --check script.js` and `node --check reviews.js`.
3. Preview using `python -m http.server 8000`.
4. Check booking links, responsive layout, and review moderation before proposing changes.
5. Do not commit patient data, private credentials or unlicensed assets.

Include screenshots only when they show the actual running site.
